# L.A.M Tech Consultancy Website

A modern, multi-page website for a tech consultancy firm. Inspired by the clean UI of Plavno, the typography of Instinctools, and the interactive 3D elements of Tallium.

## 🚀 Features
- **Interactive 3D Scene**: Powered by Three.js, featuring a floating, reactive geometric shape.
- **Custom Cursor Highlight**: A smooth radial gradient that follows the user's mouse.
- **Mega-Menu Navigation**: Hover dropdowns for Services, Solutions, and Industries.
- **Fully Responsive**: Mobile-friendly navigation and flexible grid layouts.
- **Multi-Page Architecture**: Dedicated pages for Home, Services, Solutions, Industries, and Contact.

## 🛠️ Tech Stack
- HTML5
- Vanilla CSS3 (Custom properties, Flexbox, Grid)
- Vanilla JavaScript
- Three.js (via CDN)

## 💻 How to Run
1. Clone this repository or download the files.
2. Open `index.html` in any modern web browser.
3. No build tools are required. 

## 🎨 Design System
- **Primary Color**: `#0055FF` (Vibrant Blue)
- **Dark Background**: `#0A1128` (Deep Navy)
- **Light Background**: `#F8F9FA` (Off-White)
- **Font**: Inter (Google Fonts)
